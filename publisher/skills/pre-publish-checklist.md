# Pre-publish checklist

- [ ] publisher analyze reports no FAIL.
- [ ] Facts and numbers each have a source (link or data row) you can name.
- [ ] Tone matches brand-voice; no hype, no retired codename, no emoji.
- [ ] No credentials, emails, or user-level data anywhere in the text.
- [ ] Draft is a PR or a Substack draft, not live.
- [ ] To go live (Reddit or Substack publish) the ticket carries approval_ref. If it does not,
      stop and say: drafted, awaiting Hermes approval. Never ask a human to bypass it.
- [ ] Hand back: Hive result summary (about 10 lines) with the PR link.
