# Report and hand-back

1. Hive result summary: about 10 lines, outcome first, links to PRs, open questions last.
2. Full report: Markdown file, then publisher report <slug> report.md (branch reports/<slug>).
   Reports go into a repo that may be public: no credentials, no raw rows, aggregates only.
3. Every report states: source, date range, row counts, and marks anything unchecked as untested.
4. Durable lessons go to your memory bank (skill: memory-practice) and Steward save_memory.
