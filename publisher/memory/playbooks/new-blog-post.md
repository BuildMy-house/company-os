# Playbook: ship a blog post

1. recall past decisions on the topic; pull top-queries and top-pages.
2. Write draft.json following blog-post-structure and brand-voice.
3. publisher analyze on the rendered body; fix FAILs.
4. publisher blog pr --file draft.json; hand back the PR link to Hermes.
5. After merge and a week of data: record what performed and why.
