# Marketing Domain — Agent Rules

Extends `shared/AGENTS.base.md`. Read that first.

## Domain: Marketing

Content creation, SEO, campaigns, social media, copywriting, analytics,
brand strategy, lead generation.

## Key Principles

- **Brand voice consistency**: All content must match the Homely brand guide.
- **SEO-first**: Every page, post, and campaign includes target keywords.
- **Data-driven**: decisions backed by analytics, not guesses.
- **Audience-focused**: Write for the reader, not for the company.

## Content Types

| Type | Tools | Review |
|------|-------|--------|
| Blog posts | Markdown, SEO checker | Manager + brand review |
| Landing pages | Astro components | Manager + design review |
| Social copy | Short-form text | Manager review |
| Email campaigns | Template system | Manager + compliance review |
| Documentation | Markdown, MDX | Manager review |

## Workflow

1. Manager receives brief from Hermes
2. Manager creates ticket in PLAN.md with DoD
3. Worker creates content following brand guide
4. Manager reviews for quality, SEO, brand consistency
5. Manager verifies DoD (word count, keyword density, readability)
6. Manager marks done, commits to knowledge base
